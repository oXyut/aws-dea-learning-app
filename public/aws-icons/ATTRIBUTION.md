# AWS Architecture Icons

Source: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/).

Release: July 31, 2026 (2026 Q3).

[Original icon package](https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip)

The 37 SVG files in this directory are unmodified artwork from the official AWS distribution, renamed for local use. `manifest.json` records each original archive path and SHA-256 digest. AWS provides these assets for architecture diagrams and technical materials; the AWS assets remain subject to AWS's applicable terms and are not relicensed by this project.

39 service entries use these assets. Glue ETL uses the AWS Glue service icon; Redshift Spectrum uses the Amazon Redshift service icon. Crawler, Data Catalog, and Data Quality use their dedicated resource icons, shown on a light background without altering their artwork. QuickSight retains a generic icon because this release does not contain a standalone QuickSight icon. Application nodes and interface/category icons use Lucide.

This is an independent educational application, not an official AWS product or an endorsement by AWS.
